نظام إدارة قسم الإنتاج في شركة نتش رول جروث

Netsh Roll Growth – Production Department Management System

نظام معلومات إداري يهدف إلى دعم وتنظيم العمليات التشغيلية في قسم الإنتاج بشركة نتش رول جروث، من خلال توفير منصة موحدة لإدارة الهناجر والقطعان، الإنتاج اليومي، الطلبات التشغيلية، المبيعات، عمليات التوريد للمخازن، التقارير، لوحة التحكم، والإشعارات، مع تطبيق الصلاحيات وفق أدوار المستخدمين.

«مشروع تخرج جامعي – College of Computers and Information Technology»

---

📌 نبذة عن المشروع

يهدف المشروع إلى تطوير نظام يساعد قسم الإنتاج على تنظيم البيانات والعمليات التشغيلية وتقليل الاعتماد على الإجراءات اليدوية والمتفرقة.

يركز النظام على توفير دورة عمل مترابطة تبدأ من تسجيل البيانات التشغيلية والاحتياجات، مرورًا بالطلبات ومراجعتها، ووصولًا إلى عمليات المبيعات والتوريد للمخازن والتقارير والمتابعة.

تم تصميم النظام بحيث تكون العمليات والصلاحيات مرتبطة بأدوار المستخدمين، مع مراعاة أمن البيانات وسلامتها وإمكانية تتبع العمليات.

📄 تصدير المستندات والتقارير إلى PDF والبحث الفوري

- تصدير المستندات الرسمية والتقارير المعتمدة (فواتير المبيعات، سندات التوريد للمخازن، طلبات الاحتياج، والتقارير التشغيلية الخمسة R-01 إلى R-05) إلى ملفات PDF منسقة باللغة العربية واتجاه RTL مع الترويسة الرسمية وتذييل الاعتماد وفق صلاحيات الدور.

🛠️ التقنيات

التقنيات الفعلية المستخدمة في النسخة المعتمدة للمشروع:

- Frontend: React 19 + TypeScript + Vite + Tailwind CSS
- PDF Generation: `jspdf` + `html2canvas` (تصدير مستندات وتقارير عربية RTL عالية الدقة)
- Backend: Node.js + Express (TypeScript / `tsx`)
- Database: SQLite (`node:sqlite` مع تفعيل المفاتيح الأجنبية `FOREIGN KEYS` والمعاملات الذرية `ACID`)
- Authentication & Authorization: مصادقة باستخدام Bearer Tokens موقعة بواسطة HMAC-SHA256 وتشفير كلمات المرور (`PBKDF2-SHA512`) مع التحكم بالوصول المبني على الأدوار (`RBAC`)
- API: RESTful API (`/api/*`)
- UI: Responsive Arabic RTL Interface

🚀 تشغيل المشروع

بعد استنساخ المستودع:

```bash
git clone <repository-url>
```

ثم الانتقال إلى مجلد المشروع:

```bash
cd netsh-roll-growth-production-management-system
```

وتثبيت الاعتماديات:

```bash
npm install
```

أوامر التشغيل والفحص المعتمدة في `package.json`:

- تشغيل بيئة التطوير (الخادم والواجهة على المنفذ `3000`):
```bash
npm run dev
```

- فحص الأنواع والكود البرمجي (TypeScript Check):
```bash
npm run lint
```

- بناء نسخة الإنتاج النهائية:
```bash
npm run build
```

- تشغيل الخادم في وضع الإنتاج:
```bash
npm start
```
